# politics.research — GitHub Pages

A minimalist, horizontal-feeling Instagram-style research proposal website.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.

The site uses only HTML/CSS/JavaScript and Google Fonts; there is no build step.
